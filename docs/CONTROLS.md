# Controls and settings

[← Back to README](../README.md)

The supplied `ps5-settings-default.ini` provides a customizable control and graphics configuration. These are **defaults**, not fixed mappings.

| PS5 input | Port action |
| --- | --- |
| Cross | DS A |
| Circle | DS B |
| Triangle | DS X |
| Square | DS Y |
| Options | Start |
| Touchpad click | Select |
| D-pad | Directions / command menu |
| Left stick | Movement / directions |
| L1 | DS L |
| R1 | Lock-on (default; also mapped to DS R in package notes) |
| R2 | Next target |
| R3 | DS R |
| L3 | Open port settings menu |

## Display and graphics defaults

| Option | Packaged default |
| --- | --- |
| Aspect ratio | `16:9` |
| Screen layout | `one` |
| Internal resolution | `6` (DS-resolution multiple) |
| Antialiasing | `off` |
| Scaling | `sharp` |
| HD graphics | `on` |
| HD movies | `hd` (uses available user-supplied media) |
| Show FPS | `off` |
| Rendering backend | `vulkan` |
| Online room discovery | `off` |
| Autosave | `file99` |

For the complete settings, refer to the `ps5-settings-default.ini` shipped in the release package. The game saves modified settings to its save directory.
